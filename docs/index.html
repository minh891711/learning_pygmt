這部影片是為 AGU 2021 Fall Meeting 製作的 PyGMT 快速介紹，教你如何用 Python 輕鬆建立地圖。PyGMT 是基於 GMT (Generic Mapping Tools) 的 Python 介面，專門用於地理空間資料的處理、分析與視覺化。

內容分析與重點擷取

影片聚焦三個核心任務：從簡單基底地圖到進階光柵影像繪製。適合 GIS、地球科學或資料視覺化初學者。

1. 建立簡單基底地圖

使用 Figure 類別設定區域（經緯度範圍）、投影（Mercator，20cm 寬度）與框架（自動）。這是繪圖的起點，讓你快速產生空白地圖畫布。

import pygmt fig = pygmt.Figure()
fig.basemap(region=[-180, 180, -70, 70], projection="M20c", frame=True)
fig.show()

2. 新增海岸線與顏色

透過 coast 方法繪製海岸線，將陸地塗成深綠、水域設為淺鋼藍。使用全球範圍與 Hammer 投影，展示如何美化地圖。

fig = pygmt.Figure()
fig.basemap(region="g", projection="H", frame=True)
fig.coast(land="darkgreen", water="lightsteelblue")
fig.show()

3. 繪製光柵影像

載入 SRTM 15+ 網格資料（20 角分鐘解析度），使用 PyGMT 的遠端資料集功能，自動陰影處理。完美示範進階視覺化。

with pygmt.Figure() as fig:
fig.basemap(projection="H", region="g", frame=True)
fig.grdimage(grid="@earth_relief_15s", shading=True)
fig.show()
